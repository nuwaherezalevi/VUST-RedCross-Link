# VUST RedCross Link Website

A responsive, static multi-page website concept developed by **NL DIGITAL LABs CENTER**.

## Pages
- `index.html` — Homepage
- `about.html` — Background, vision, mission, values and principles
- `programmes.html` — Programme descriptions based on the supplied Constitution
- `get-involved.html` — Membership, volunteering, training and partnerships
- `news.html` — News and activity publishing framework
- `resources.html` — Constitution and organizational resources
- `contact.html` — Contact details and email handoff enquiry form

## Run locally
1. Extract the ZIP file.
2. Open the `vust-redcross-link-website` folder.
3. Double-click `index.html`, or use a local development server such as VS Code Live Server.
4. Navigate using the menu.

No build tools or package installation are required.

## Customize
- Edit page text in the relevant `.html` file.
- Change colors, fonts, spacing and layout in `assets/styles.css`.
- Update menu behavior and contact form handoff in `assets/script.js`.
- Replace the remote Unsplash images in CSS with approved organization photographs.
- Add real event reports, testimonials, impact figures and leadership profiles only after verification and approval.

## Important launch checks
1. The supplied Constitution is titled **Draft 1, 2026** and has blank adoption and approval fields. Confirm the current approved constitutional version and institutional recognition status before publishing final claims.
2. The Red Cross emblem is protected. The current design uses an abstract letterform mark, not the emblem. Use the emblem, uniforms or official marks only with appropriate authorization and in line with Uganda Red Cross Society policy.
3. The contact form uses a `mailto:` handoff. It does not store submissions. For production, connect a secure form backend or approved form service, add spam protection and publish a privacy notice.
4. Add approved photos with informed consent, safeguarding review and image rights clearance.
5. Add verified testimonials, impact data, office hours, social media links and actual activity calendar when available.
6. Review accessibility, privacy, safeguarding, security and mobile behavior before launch.
